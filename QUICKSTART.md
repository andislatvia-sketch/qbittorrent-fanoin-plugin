# FANO.IN Plugin - One-Line Installation Guide\n\n## No Guesswork. Just Copy-Paste.\n\n---\n\n## Step 1️⃣: Install the Plugin (30 seconds)\n\n**Open qBittorrent and follow these exact steps:**\n\n1. Click **View** → **Search Engine**\n2. Click **Search plugins...** (bottom right)\n3. Click **Install a new one**\n4. Select **Web link**\n5. **Copy and paste this exact URL:**\n\n```\nhttps://raw.githubusercontent.com/andislatvia-sketch/qbittorrent-fanoin-plugin/main/fanoin.py\n```\n\n6. Click **Install**\n7. Restart qBittorrent\n\n✅ **Plugin installed.**\n\n---\n\n## Step 2️⃣: Add Your Credentials (1 minute)\n\n**Find your engines folder:**\n\n### Windows Users:\n1. Press `Win + R`\n2. Copy and paste this:\n```\n%localappdata%\\qBittorrent\\nova3\\engines\\\n```\n3. Press Enter\n4. A folder opens\n\n### Linux Users:\nOpen terminal and run:\n```bash\ncd ~/.local/share/qBittorrent/nova3/engines/\n```\n\n### macOS Users:\nOpen terminal and run:\n```bash\ncd ~/Library/Application\\ Support/qBittorrent/nova3/engines/\n```\n\n---\n\n## Step 3️⃣: Create the fanoin.json File\n\n**In the engines folder:**\n\n### Windows (Easiest):\n1. Right-click in the folder\n2. Select **New** → **Text Document**\n3. Name it `fanoin.json`\n4. Right-click on it → **Open with** → **Notepad**\n5. Paste this exact text (replace username and password):\n\n```json\n{\n  \"username\": \"your_fano_username\",\n  \"password\": \"your_fano_password\"\n}\n```\n\n**Example:**\n```json\n{\n  \"username\": \"john_doe\",\n  \"password\": \"MyPassword123!\"\n}\n```\n\n6. **Ctrl+S** to save\n7. Done!\n\n### Linux/macOS:\nRun this command (replace `username` and `password`):\n\n```bash\ncat > ~/.local/share/qBittorrent/nova3/engines/fanoin.json << 'EOF'\n{\n  \"username\": \"your_fano_username\",\n  \"password\": \"your_fano_password\"\n}\nEOF\n```\n\n---\n\n## Step 4️⃣: Verify It Works\n\n1. **Restart qBittorrent** (close and open it)\n2. Go to **Search** tab\n3. Select **FANO.IN** from the dropdown\n4. Search for anything (e.g., \"ubuntu\")\n5. If results appear → ✅ **You're done!**\n\n---\n\n## ❌ If It Doesn't Work:\n\n### Problem: \"404 Not Found\" when installing\n\n**Solution:**\n- Copy the URL again (exactly):\n  ```\n  https://raw.githubusercontent.com/andislatvia-sketch/qbittorrent-fanoin-plugin/main/fanoin.py\n  ```\n- Try installing again\n- Make sure qBittorrent is fully closed before restarting\n\n### Problem: \"Login failed\" after installing\n\n**Solution:**\n1. Check if `fanoin.json` is in the correct folder\n2. Verify your username and password are correct at fano.in\n3. Check the JSON format (use https://jsonlint.com/ to validate)\n4. Delete `fanoin.cookies` file in the same folder\n5. Restart qBittorrent and try again\n\n### Problem: No search results\n\n**Solution:**\n1. Make sure you're logged into FANO.IN website (check account is active)\n2. Try a simpler search query\n3. Check your internet connection\n4. Delete `fanoin.cookies` and retry\n\n---\n\n## 📁 File Structure (What you should have)\n\nAfter completing all steps, your engines folder should look like:\n\n```\nC:\\Users\\YourName\\AppData\\Local\\qBittorrent\\nova3\\engines\\ (Windows)\nor\n~/.local/share/qBittorrent/nova3/engines/ (Linux)\nor\n~/Library/Application Support/qBittorrent/nova3/engines/ (macOS)\n\n├── fanoin.py           ← The plugin (auto-installed)\n├── fanoin.json         ← Your credentials (you created)\n└── fanoin.cookies      ← Auto-created after first login\n```\n\n✅ **If you see these 3 files, everything is set up correctly.**\n\n---\n\n## 🔐 Security Notes\n\n✅ **DO:**\n- Keep `fanoin.json` on your computer only\n- Use a strong, unique password\n- Never share `fanoin.json` with anyone\n\n❌ **DON'T:**\n- Upload `fanoin.json` to GitHub or internet\n- Share your FANO.IN credentials\n- Edit `fanoin.py` (keep it as-is)\n\n---\n\n## 🆘 Still Stuck?\n\n1.
